# Icons

Tauri requires a platform icon set here (`32x32.png`, `128x128.png`,
`128x128@2x.png`, `icon.icns`, `icon.ico`).

Generate them from any square PNG (1024×1024 recommended):

```bash
npx tauri icon ./path/to/logo.png
```

The command writes all required files into this directory.

Alternatively, copy the defaults produced by `npm create tauri-app`.
